# SportA Admin

Back-office MUI du MVP SportA Student. Il partage les mêmes parcours et
données métier que l’application Flutter : joueurs, familles, coachs,
réservations, séances, progression, tournois et communication.

## Commandes

- `npm run dev` : développement local
- `npm run lint` : contrôle ESLint
- `npm run build` : compilation TypeScript et build Vite de production

Les données sont simulées dans `src/data.ts` et pourront être remplacées par
des repositories ou une API sans modifier les composants de présentation.
