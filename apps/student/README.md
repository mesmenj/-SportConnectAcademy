# SportA Student

A new Flutter project.

## Déploiement Vercel

Le dépôt contient `vercel.json`, qui compile Flutter Web et publie
`build/web`. Dans les paramètres Vercel, le **Root Directory** doit être la
racine de ce dépôt (le dossier qui contient `pubspec.yaml` et `vercel.json`).
Les commandes Build et Output Directory de l'interface Vercel peuvent rester
vides afin d'utiliser cette configuration.
